# 🌌 Mokshit S — Interactive Stranger Things Portfolio

An immersive, retro-inspired creative developer portfolio inspired by the atmosphere of *Stranger Things*, featuring custom WebGL dimensional shaders, interactive alphabet wall mechanics, Hawkins Lab CRT monitor security archives, and an 80s D&D character dossier.

---

## ⚡ Key Features

- **Dimensional Reveal Hero:** Interactive fluid tearing WebGL shader bridging the Hawkins surface world with the Upside Down realm.
- **80s D&D Character Dossier:** Vintage parchment manual layout featuring custom character stats, lore, and radio transmission contact modal.
- **Byers Living Room Alphabet Wall:** Interactive lightbulb wall spelling system with dynamic point lights, glow diffusion, and project expedition dossiers.
- **Hawkins Lab CCTV Surveillance Wall:** Multi-channel security CRT monitor wall showcasing verified certifications and achievements with realistic scanlines and TV chassis.
- **Authentic 80s Aesthetics:** Custom typography, CRT scanlines, atmospheric ambient spore particles, and analog radio sound effects.
